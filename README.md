# Java Practice

Small Java programs from my first stage of learning Java (Swing dialogs, conditionals, arrays). Written in NetBeans; each folder is one program.

| Folder | What it does |
|---|---|
| `grade-checker/` | Asks for marks in a dialog box and shows the grade (A+ to Fail) |
| `array-basics/` | 2D array declaration and printing with `Arrays.deepToString` |
| `java-basics/` | Methods, input handling and dialog exercises (older exercises are left commented out as written) |

For a larger Java project see [pomodoro-timer-java](https://github.com/zaynisthatu/pomodoro-timer-java), a Swing Pomodoro timer.

## Run
Needs a JDK (`javac`, `java`). Example:
```
cd grade-checker
javac GradeChecker.java
java gradechecker.GradeChecker
```
Files declare a package (`gradechecker`, `myfirstarray`, `firstjavaprogram`), so compile from the folder and run with the package name, or open in NetBeans.
